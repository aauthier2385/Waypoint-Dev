A free Linux system for learning to code, built for complete beginners.

## Download

Under **Assets** below, download **waypoint-dev-@VERSION@-amd64.iso**.

Then follow the [step-by-step install guide](https://github.com/aauthier2385/Waypoint-Dev#readme). It covers putting the file on a USB drive, starting your PC from it, installing, and getting set up.

**SHA-256:** `@SHA256@`

Checking this is optional, but it confirms the download arrived complete. The guide shows how.

## What's included

- Debian 13 with the lightweight XFCE desktop, for older BIOS PCs and newer UEFI PCs
- A newer kernel and firmware for recent hardware
- VS Code, Git, and GitHub sign-in, set up from the first start
- Waypoint Welcome: pick websites, Python, games, phone-friendly apps, or Rust, and get the tools plus a starter project
- A built-in Rust course with 33 lessons, from beginner to advanced, that checks your work in plain English
- `dev doctor` for finding and fixing common problems, and undo snapshots
- Updates for Waypoint and its lessons through `sudo apt update && sudo apt upgrade`

## Good to know

- This is an early release, tested on a small number of PCs. Please [report](https://github.com/aauthier2385/Waypoint-Dev/issues) what does and doesn't work on yours.
- Back up anything important before installing alongside another system.
- Claude Code needs a processor from about 2013 or newer. On older PCs, use Claude at claude.ai in Firefox.
- NVIDIA's own graphics driver can't be used while Secure Boot is on. The built-in driver works fine for coding.
