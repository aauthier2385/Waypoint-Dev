# Your first game

1. Press **Ctrl+Shift+B** to run the game. Use the left and right arrow keys.
2. In `main.py`, change `PLAYER_SPEED`, save, and run it again.
3. Change the star's color. Colors are written as (red, green, blue), from 0 to 255.
4. Make the stars fall a little faster each time the player scores.
