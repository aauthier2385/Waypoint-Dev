# Your first phone-friendly app

1. Press **Ctrl+Shift+B** to run the project.
2. Open <http://localhost:3000> in Firefox and press **Add one**.
3. Close the tab and open it again. Your tally is still there because it's saved in the browser.
4. In `public/index.html`, rename the app. Change the name in `public/manifest.webmanifest` too.
5. In `public/app.js`, add a button that subtracts one.

To put this on a real phone, it needs to be hosted on a website with HTTPS. Your phone can then add it to its home screen.
