# Your first website

1. Press **Ctrl+Shift+B** to run the project. You can also use **Terminal > Run Build Task**.
2. Open <http://localhost:3000> in Firefox.
3. In `public/index.html`, change the heading, save with **Ctrl+S**, then refresh Firefox.
4. In `public/style.css`, change the `background` color and refresh again.
5. In `public/app.js`, make the button count by two.

To stop the server, click the terminal and press **Ctrl+C**.
